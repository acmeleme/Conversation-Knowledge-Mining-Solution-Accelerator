# Architecture Decision Records

This folder stores Architecture Decision Records (ADRs) for the Conversation-Knowledge-Mining-Solution-Accelerator.

Use ADRs to document decisions that shape the solution architecture, such as platform choices, integration patterns, security boundaries, storage strategy, and AI orchestration.

Conventions:
- use incremental numbering: `ADR-0001`, `ADR-0002`, ...
- keep one decision per file
- record context, decision, consequences, and follow-up items
- reference related feature specs and implementation plans when applicable
