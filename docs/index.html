Conversation Knowledge Mining

Extraia insights acionáveis de grandes volumes de dados conversacionais usando inteligência artificial avançada.

Quick Start

📊 Visão Geral da Solução

A solução Conversation Knowledge Mining foi desenvolvida para extrair insights acionáveis de grandes volumes de dados conversacionais, identificando padrões, temas-chave e relacionamentos significativos em diálogos.

Value Proposition

  • Análise em Escala: Processa grandes volumes de transcrições de áudio e texto
  • Extração de Insights: Identifica padrões, tendências e relacionamentos automáticamente
  • Decisões Mais Rápidas: Enables natural language exploration dos dados
  • Qualidade Aprimorada: Melhora nos processos de contato center e satisfação do cliente

Principais Capacidades

🎯 Topic Modeling

Identifica temas e padrões de conversa automaticamente usando processamento de linguagem natural avançado.

🔑 Key Phrase Extraction

Extrai frases-chave e entidades relevantes de conversas para análise estruturada.

🎙️ Transcrição de Áudio

Converte automaticamente arquivos de áudio em texto estruturado e indexado.

💬 Chat Interativo

Interface de linguagem natural para exploração de dados e geração de insights em tempo real.

🎬 Business Scenario

Problema

Grandes volumes de dados conversacionais de call centers, atendimento ao cliente e comunicações internas não são sistemática e eficientemente explorados para extrair insights de negócio.

Usuários-Alvo

  • Analistas de Centro de Contato: Identificam tendências de qualidade e satisfação
  • Gerentes de Operações: Monitoram KPIs e avaliam desempenho de equipes
  • Líderes de Negócio: Tomam decisões estratégicas baseadas em insights de clientes
  • Equipes de Conformidade: Garantem qualidade e conformidade nas conversas

Use Cases

  • Identificar tendências de reclamações e problemas recorrentes
  • Monitorar qualidade de atendimento e performance de agentes
  • Descobrir oportunidades de venda e upsell
  • Análise de satisfação e NPS automática
  • Conformidade e auditoria de conversas

📁 Estrutura de Dados

Tipos de Dados Processados

Entradas:

  • Arquivos de áudio (WAV, MP3, etc.)
  • Transcrições de texto
  • Metadados de conversas (data, duração, agente)

Saídas Processadas:

  • Transcrições estruturadas com timestamps
  • Entidades e frases-chave extraídas

  • Tópicos e clusters de conversas

🤖 Semantic Kernel Agents

A solução utiliza 4 agents especializados que trabalham em conjunto para processar e responder a consultas sobre dados conversacionais:

Conversation Agent

Orquestra conversas naturais com usuários, mantém contexto e coordena outros agents para responder perguntas complexas sobre dados conversacionais.

Context Aware Multi-turn

Search Agent

Busca e recupera informações relevantes de transcrições usando busca semântica, keyword matching e filtros estruturados para encontrar conversas pertinentes.

Semantic Search Hybrid

SQL Agent

Executa queries SQL complexas para análise agregada de dados, estatísticas e insights de negócio sobre tópicos, sentimentos e padrões de conversas.

Analytics Aggregations

Chart Agent

Gera visualizações de dados - gráficos, dashboards e relatórios - para comunicar insights de forma clara e impactante.

Visualization Real-time

Fluxo de Coordenação

Os agents trabalham de forma orquestrada:

  1. Conversation Agent recebe a pergunta do usuário
  2. Determina qual agent(s) executar (Search, SQL, Chart)
  3. Search/SQL Agents processam e retornam resultados
  4. Chart Agent visualiza os dados conforme necessário
  5. Conversation Agent sintetiza resposta final natural

🏗️ Arquitetura Técnica

A arquitetura segue um padrão de processamento em pipeline, combinando serviços Azure gerenciados para processamento, indexação e entrega de insights.

Componentes Principais

Componente Função Serviço Azure
Storage Armazena áudio, transcrições e arquivos de entrada Storage Account
Processing Extrai entidades, tópicos e estrutura de conversas AI Content Understanding
Indexação Indexa dados para busca semântica e keyword AI Search
Database Armazena dados estruturados e metadados SQL Database
LLM & Orchestration Fornece capacidades de IA e coordena agents Azure OpenAI + Semantic Kernel
API & Web Interface web e APIs REST App Service
Session Context Persiste histórico de conversas Cosmos DB

Fluxo de Dados

  1. Ingestão: Áudio/transcrições → Storage Account
  2. Processing: AI Content Understanding → Extração de dados estruturados
  3. Indexação: SQL Database + AI Search com embeddings
  4. Consulta: Agents buscam em Storage → Search/SQL → LLM
  5. Resposta: Conversation Agent sintetiza → Web UI

🛡️ Guardrails & RBAC

A solução implementa dois mecanismos de controle para garantir comportamento seguro e correto do agente IA:

🔒 Guardrails — Controle de Conteúdo

O agente recusa educadamente perguntas fora do contexto financeiro:

  • Off-topic: Receitas, meteorologia, notícias gerais → resposta educada redirecionando ao domínio financeiro
  • Prompt Injection: Tentativas de alterar o comportamento do agente bloqueadas
  • Jailbreak: Instruções maliciosas detectadas e ignoradas
  • Busca na web: Agente restrito à base de conhecimento local (sem acesso externo)

🔐 Login UI — Tela de Seleção de Perfil

A interface web inclui uma tela de login demo que permite demonstrar o RBAC diretamente no navegador, sem necessidade de curl ou ferramentas de desenvolvedor:

💼 Financeiro & Faturamento

Acesso total a todos os tópicos, incluindo Cartão de Crédito — Fatura e Pagamento e Cartão de Crédito — Bloqueio e Contestação.

Acesso a todos os tópicos exceto tópicos de Cartão de Crédito. Ao tentar acessar tópicos restritos, recebe resposta de bloqueio educada.

👁️ Visitante / Demo

Acesso padrão ao callcenter. Ideal para apresentações gerais da solução sem contexto de roles específicos.

A tela de login é gerenciada pelo componente React LoginPage.tsx. O papel selecionado é persistido em localStorage["demo-role"] e injetado como header x-demo-role em toda chamada à API via api.ts::apiFetch(). O header do app exibe um badge com o perfil atual e um botão de logout que limpa o estado.
